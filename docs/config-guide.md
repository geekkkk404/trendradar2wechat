# 配置指南（个性化你的 TrendRadar）

> 适用于本仓库一键脚本部署的 TrendRadar（含 `--wechat-bridge`，安装目录默认 `/opt/TrendRadar`）。
> **主通道：微信对话，装完之后不再需要碰终端。** 文件编辑保留给深度玩家与急救场景。

## 主通道：在微信里管一切

部署完成后，打开微信里授权时创建的 **bot 会话**（「微信 ClawBot」），发消息即可：

| 发送 | 效果 |
|---|---|
| `推送` / `获取` / `新闻` | **立即抓取并推送最新热点**（拉取模式核心指令） |
| `帮助` | 指令菜单 |
| `状态` | 当前配置速览（推送/拉取/分组/平台/词表规模/AI） |
| `词表` | 查看关注关键词 |
| `暂停` / `恢复` | 停止 / 恢复推送（抓取照常） |
| `触发词` / `加触发词 X` / `删触发词 X` | 自定义拉取触发词 |
| `TRCFG1:…` | 应用一串配置码，约 1 分钟后收到新样式推送 |
| `设置AI密钥 sk-xxx` | 开启 AI 热点分析（见下方专节） |
| `测试AI` / `删除AI配置` | 立即验证 AI 连通 / 关闭并删除 Key |

> **拉取模式（默认）**：v0.5.0 起微信桥安装默认不做定时推送——你发「推送」「获取」「新闻」等触发词时才抓取并推送当下最新热点。这既贴合「想看才看」的使用习惯，也顺应微信 bot 协议的安全设计（机器人只在应答时发言，最稳）。想要每 30 分钟自动推送的经典模式：重跑安装脚本加 `--enable-timer`。

### 可视化配置页（生成配置码）

不想记指令？打开 **[geekkkk.com/trcfg](https://geekkkk.com/trcfg/)**（本博客的静态工具页，无后端）：

1. **从模板开始（可选）**：四套按典型场景配好的整套配置，点一下自动填进表单再随意增删——
   - 🔥 **全网热点**（装机默认）：六大热点平台热榜直出、按来源分组，「热点速览」每轮最多 20 条防刷屏
   - 💻 **极客开发**：Hacker News/知乎/B站 + AI 前沿与工程开发主题，屏蔽娱乐圈
   - 📈 **商业财经**：华尔街见闻/财联社/雅虎财经 + 宏观政策与产业大盘，屏蔽八卦
   - 📰 **硬新闻脱水**：澎湃/凤凰/百度三权威源，只靠屏蔽词滤掉娱乐八卦
2. 或像点外卖一样自由勾选：**关注主题**（关键词卡片）、**推送分组**、**信息源**（11 个热榜平台 + RSS）。本项目为拉取模式：没有定时推送，想看热点时在微信发「推送 / 获取 / 新闻」即抓即推
3. 点「生成配置码」→「复制」
4. 切到微信，粘贴给 bot 发送 → 收到「✅ 配置已应用」→ 约 1 分钟后收到新样式推送

> **为什么要有限流阀**：关注词全部留空 = 推送全部热榜（六平台全量一次约 5-6 条连发消息，既刷屏也容易触发微信风控）。「全网热点」「硬新闻脱水」两套模板用「热点速览」兜底组（匹配一切 + 每轮 20 条上限）把推送压回安全量级——自己玩空词表时建议保留类似限流。

配置码只是一段数据：不含任何账号凭证、不是命令；真正修改配置的是你自己服务器上的管家，且**只接受页面上那些选项**（服务端白名单校验，配置码里塞别的一律拒收）。已生成的配置码可以粘贴回页面「导入」，恢复成表单继续改。

### AI 热点分析（可选，自备 Key）

每期推送可附带一段 AI 对当前热点的解读（脉络梳理 / 情绪与争议 / 值得关注的信号）。这需要你自己的大模型 API Key，微信里两条指令就能开启：

**推荐：腾讯 TokenHub（新用户有免费额度）**

1. 打开 [console.cloud.tencent.com/tokenhub](https://console.cloud.tencent.com/tokenhub)，用腾讯云账号（买 VPS 时注册的那个）登录，开通服务时可选**「仅使用免费额度」**（零付费风险）
2. 在「快速接入」页点「创建 API Key」，复制 `sk-` 开头的密钥
3. 微信给 bot 发：`设置AI密钥 sk-你的密钥`
4. 收到「✅ AI 分析 → 已启用」小票，下一期推送起自动附带 AI 段；发 `测试AI` 可立即验证连通

默认模型为 **deepseek-flash**（DeepSeek 原厂直供，速度与质量在本场景实测最佳）。新用户每款模型赠 100 万 tokens（有效期 1 年，按每期推送消耗几千 tokens 计约够数百期）；**额度用尽后**需在控制台开通后付费继续使用，或随时发 `删除AI配置` 关闭（关闭后回到默认省流模式，不再出现 AI 段与相关提示）。

**用 DeepSeek 官方直连的读者**：发 `设置AI密钥 sk-你的密钥 官方`（结尾加「官方」二字），按 DeepSeek 官方价目计费。

**其他第三方**（OpenAI / Gemini / 中转站 / 私有部署）：微信指令只覆盖上面两种。想切换模型、配网关、用备用模型或开启 AI 智能筛选/翻译的深度玩家，请按 TrendRadar 上游文档编辑 **`user-config/config.yaml`** 的 `ai:` 节——注意上游文档写的是 `config/` 目录，本部署已把配置外置到 `user-config/`，**改错位置不会生效**。改完下个抓取周期自动生效。

**Key 安全说明**：Key 保存在服务器的 `trendradar.env`（权限 600，仅 root 可读）；微信回执与日志只显示打码形式（如 `sk-TJ5******`）；配置码与导出链接永远不含 Key。如怀疑泄露，去控制台重置 Key 后重发 `设置AI密钥` 即可。

## 你的配置在哪（文件视图）

| 文件 | 管什么 |
|---|---|
| `user-config/frequency_words.txt` | 关注关键词与屏蔽词（默认=「全网热点」模板的热点速览限流阀；TRCFG1 应用后由管家整体重写） |
| `user-config/config.yaml` | 主配置（上游 24KB 中文注释模板的**手术式副本**，注释原样保留） |
| `trendradar.env` | 渠道凭证与接线（微信桥、AI key 等），一般不动 |

`user-config/` 是安装脚本为你开辟的专属目录：**升级 / 重跑安装脚本永不覆盖**（只在首次安装时从上游模板播种一次）。想恢复出厂：删掉 `user-config/` 里对应文件再重跑安装脚本。

## 生效时机

- 微信指令 / 配置码：管家应用后**自动触发一轮抓取**，约 1 分钟内收到新样式推送
- 拉取模式（默认）：微信发「推送 / 获取 / 新闻」→ 现抓现推当下热点；手工编辑 user-config 文件后同样发「推送」即可验证
- 经典定时模式（`--enable-timer`）：每 30 分钟一轮自动抓推；手工编辑文件改完最多等半个周期
- 端口、安装形态（`--no-web` / `--with-mcp` 等）是安装期选项，重跑安装脚本传对应参数（幂等，配置与数据保留）

## 深度编辑（可选）

`user-config/config.yaml` 内含上游的完整中文注释，微信页没有暴露的高级项（AI 筛选、存储后端、爬虫代理等）直接改文件即可，下个周期自动生效。关键词文件的语法（正则、组别名等全部玩法）看 `user-config/frequency_words.txt` 内的上游教学注释。

## 故障排查与急救

```bash
journalctl -u trendradar-fetch -n 50     # 抓取/推送日志（跟踪 -f）
journalctl -u any2wechat       -n 20     # 微信桥日志
journalctl -u tr2w-handler     -n 20     # 微信指令管家日志
systemctl list-timers trendradar-fetch*  # 确认定时任务在排程
```

- 抓取偶尔失败（数据源抖动）属正常，下一轮自动重试
- **微信通道失灵时**（桥故障 / 需重新扫码 / 协议变更），配置照样能改：
  1. 编辑 `user-config/` 下文件（nano/vi），下个周期自动生效；
  2. 或把配置码存成文件走急救 CLI（与微信指令同一白名单核心）：
     `python3 /opt/TrendRadar/tr2w/apply_trcfg.py 载荷.json`
- 每次管家应用配置前都会自动备份到 `user-config/.backup/`（保留最近 30 份），改坏了可从中找回
- 任何情况下重跑安装脚本都是安全的（幂等），它会补齐服务、更新源码，但不动你的 `user-config/`
